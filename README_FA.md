# Accounting CRM V2 - سامانه سبک حسابداران روی cPanel

این نسخه برای جایگزینی نسخه قبلی طراحی شده و روی همان PHP + MySQL هاست اشتراکی cPanel اجرا می‌شود؛ بدون Node، Redis، Composer یا سرویس دائمی.

## تغییرات اصلی نسخه ۲

- داشبورد جدید با کارت‌های تخصصی: بانک‌ها، حقوق و دستمزد، بیمه تامین اجتماعی، مالیات حقوق، مودیان، دفاتر الکترونیکی، اجاره و حق امتیاز، اظهارنامه عملکرد و حق‌الزحمه
- حذف ستون روزهای حضور از اطلاعات شرکت
- ستون‌های جدید شرکت: نوع شرکت، شخصیت، نرم‌افزار، آدرس، شماره ثبت، کدپستی، مدیرعامل، کدملی مدیرعامل، موبایل مدیرعامل، تلفن، شناسه ملی و کد اقتصادی
- منوی برنامه روزانه: تاریخ، روز، شرکت، شرح کار، موقعیت، توضیحات
- منوی برنامه ماهانه: شرکت، ماه، فصل، نوع کار، مهلت قانونی، وضعیت، روز انجام، تاریخ انجام
- CRUD کامل در بخش‌های اصلی
- ویرایش مستقیم داخل جدول و ComboBox برای شرکت/وضعیت/نوع کار
- حذف رکورد با دکمه سریع داخل جدول
- فیلترهای حرفه‌ای برای هر لیست
- طراحی مینیمال‌تر، کوچک‌تر و کم‌اسکرول‌تر
- Auto-save فرم‌ها در مرورگر؛ اگر تب بسته شود، داده فرم از بین نمی‌رود
- تاریخ شمسی در نمایش و ورود تاریخ‌ها
- کانبان برای کارهای ماهانه
- فیلدهای اضافه قابل تعریف توسط کاربر برای ستون‌های دلخواه
- API پایه برای اتصال آینده به Hermes، RAG و AI Agent
- تنظیمات سرویس جانبی/خانگی برای سناریوی Hybrid یا Edge Worker

## دیتابیس و مایگریشن

بعد از دیپلوی نسخه جدید، دستی جدول نسازید. وارد پنل شوید و از مسیر زیر اجرا کنید:

```text
تنظیمات > اجرای مایگریشن دیتابیس
```

یا این آدرس را بعد از لاگین باز کنید:

```text
/migrate_v2.php
```

`app/config.php` حفظ می‌شود و اطلاعات دیتابیس قبلی دست نمی‌خورد.
