# Accounting CRM V3 — تقویم کاری حسابداران روی cPanel

نسخه ۳ برای جایگزینی مستقیم نسخه قبلی روی همان پروژه PHP + MySQL و همان Git/cPanel طراحی شده است. این نسخه به Node، Redis، Composer یا سرویس دائم نیاز ندارد و روی هاست اشتراکی اجرا می‌شود.

## رابط کاربری نسخه ۳

سایدبار فقط این بخش‌ها را دارد و ترتیب آن ثابت است:

1. تقویم
2. اطلاعات شرکت‌ها
3. سامانه‌ها
4. برنامه ماهانه
5. برنامه روزانه
6. فیلدهای اضافه
7. کانبان
8. تنظیمات

صفحه اول دیگر داشبورد آماری نیست و به یک تقویم کاری ماهانه شمسی تبدیل شده است. کارهای برنامه روزانه و سررسیدهای برنامه ماهانه روی روز مربوط نمایش داده می‌شوند و با کلیک روی روز، جزئیات در مودال باز می‌شود.

## مایگریشن دیتابیس

بعد از Deploy نسخه ۳، دیتابیس را در phpMyAdmin به‌صورت دستی تغییر ندهید.

پس از ورود به سامانه این آدرس را باز کنید:

```text
/migrate_v2.php
```

نام فایل برای سازگاری با Deployment قبلی حفظ شده، اما Migration فعلی Schema نسخه ۳ را اجرا می‌کند.

Migration:

- ستون‌های جدید شرکت‌ها را اضافه می‌کند.
- جداول `daily_plans` و `monthly_plans` را ایجاد/تکمیل می‌کند.
- جداول `portal_definitions` و `portal_credentials` را برای سامانه‌ها ایجاد می‌کند.
- داده‌های جدول قدیمی `systems` را در صورت امکان به ساختار جدید منتقل می‌کند.
- خطای قدیمی `SHOW COLUMNS ... LIKE ?` را ندارد و بررسی Schema از `INFORMATION_SCHEMA` انجام می‌شود.
- جدول‌های قدیمی را برای جلوگیری از حذف ناخواسته داده نگه می‌دارد، اما در رابط کاربری نمایش نمی‌دهد.

## Deploy با Git روی cPanel

بعد از اعمال Patch روی پروژه لوکال:

```powershell
git status
git add .
git commit -m "Upgrade accounting CRM to calendar V3"
git pull --rebase origin main
git push origin main
```

سپس در cPanel روی Repository فعال:

```text
Update from Remote
Deploy HEAD Commit
```

و سپس Migration را اجرا کنید.
